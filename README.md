For this project we are planning on using the iterative design methodology. We don't have a perfectly clear idea of what the game is going to be so iterative design will work better than waterfall design. It allows us to keep going back and changing our project until we reach the final product. It will allow us to get feedback from previous designs and improve our final one. Roan will be in charge of the main coding for the game. Finn will be in charge of the art and animation. We are going to create an entirely new game this quarter. We don't know which platform we are going to use exactly yet but we might try and learn to use unity to make our game.
